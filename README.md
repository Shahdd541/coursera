# Wanderlust Guide - Travel Recommendations Website

Wanderlust Guide is a clean, multi-page static website designed to showcase curated travel recommendations across countries, beaches, and historic temples. It provides an intuitive user interface and a functional contact form for user engagement.

---

## 🚀 Features

*   **Multi-Page Navigation:** Seamless transit between the Home, About, and Contact pages with an active page highlighing mechanism.
*   **Curated Country Spotlights:** Displays featured destinations (like Japan) complete with high-quality visual galleries.
*   **Categorized Travel Recommendations:** Dedicated sections for top-tier beach and historic temple getaways.
*   **Interactive Contact Form:** A clean, styled submission form for users to get in touch with the agency.
*   **Responsive Styling:** Built with semantic HTML5 and clean CSS layouts.
